# CIRCUIT: bridge-slime-3 piston-bridge 3 gap 3 cells, width 1 cell, extend 3 gt, retract 3 gt, walkway slime block, flips safe (the lever flipped back at any time), 6 blocks, 3x1x5, robust
# A hidden bridge over a gap of 3 blocks (6 blocks, 3x1x5): flip the lever on and a row of 3 slime
# blocks slides out of the side wall into the gap; flip it off and the row slides back flush into
# the wall, leaving the gap open.
# How it works: one sticky piston behind the middle of the row pushes it, and slime blocks stick
# together, so the whole row moves as one. The ground at both ends is obsidian, which slime cannot
# pull (stone there would be dragged back with the row). Keep the other cells next to the slime row
# empty: slime drags any block it touches. Slime slows a walker a little (pext).
name: bridge-slime-3
circuit: piston-bridge 3
travel: 0 0 1
port gap: 0 0 0
port input: -3 0 1 lever
origin: -3 0 -1
palette:
  O minecraft:obsidian
  S minecraft:slime_block
  P minecraft:sticky_piston[extended=false,facing=east]
  L minecraft:lever[face=wall,facing=west,powered=false]
layer 0:
  ...O
  ..S.
  LPS.
  ..S.
  ...O
