# CIRCUIT: bridge-stone-8 piston-bridge 8 gap 8 cells, width 1 cell, extend 3 gt, retract 3 gt, walkway stone, flips safe (the lever flipped back at any time), 21 blocks, 4x1x10, robust
# A hidden bridge with a stone walkway over a gap of 8 blocks (21 blocks, 4x1x10): flip the lever on and a
# row of 8 stone blocks slides out of the side wall into the gap; flip it off and the row slides back
# flush into the wall, leaving the gap open. Stone walks like normal ground (no slime underfoot).
# How it works: behind the stone row are two sticky rows, slime then honey (slime and honey do not
# stick to each other), each with its own sticky piston behind it: one piston moves at most 12 blocks.
# The pistons push the sticky rows, which push the stone into the gap; coming back, the sticky blocks
# pull the stone home. The lever stands on an obsidian block between the two pistons and powers both
# (obsidian, because slime would drag any other block along) (pext).
name: bridge-stone-8
circuit: piston-bridge 8
travel: 0 0 1
port gap: 0 0 0
port input: -3 1 4 lever
origin: -3 0 -1
