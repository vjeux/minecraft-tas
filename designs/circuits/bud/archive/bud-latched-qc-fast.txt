# CIRCUIT: bud-latched-qc-fast bud detects place remove state update, latency 1 gt, reset manual, off 3 gt after it, re-arm 2 gt, footprint 5 cells, tileable every 3 (0 0 3), 7 blocks, 3x3x3, robust
name: bud-latched-qc-fast
circuit: bud
# Turns on at the first block update next to the target and stays on until you reset it, reacting
# in 1 tick: the fastest latched BUD (7 blocks), copies every 3 blocks. Detail: a sticky piston
# armed by quasi-connectivity (power that reaches it only through the block above its neighbor, so
# it has not noticed it) pushes a stone off the step between two dusts in the tick after the
# update; the low dust joins the powered high one and lights the output, and the piston stays out.
# The reset input is the arming redstone block: taking it away makes the piston pull the stone back
# (the output goes off 3 ticks later); putting it back arms it silently. The output is the low
# dust's own level.
tile: 0 0 3
port input.reset: 1 1 0 minecraft:air minecraft:redstone_block
port output: 1 -1 0
port target: -1 0 0
origin: 0 0 0
