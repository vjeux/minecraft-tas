# CIRCUIT: bud-observer-stone bud detects place remove state shape, latency 2 gt, pulse 2 gt, re-arm 4 gt, footprint 1 cell, tileable every 1 (0 0 1), 2 blocks, 2x1x1, robust
name: bud-observer-stone
circuit: bud
tile: 0 0 1
# The tileable observer BUD: an observer facing the target powers a stone block behind it, and the
# output lamp sits beyond the stone. Copies side by side (targets every block) do not cross-talk:
# each lamp is lit through its stone, so it is not strongly powered and does not light the next
# lamp, which a lamp right behind an observer would. Detects any real change of the target block
# (placed, removed, a property changed, even by shape updates alone), not a pure block update.
origin: -2 0 0
port target: 0 0 0
port output: -3 0 0
palette:
  O minecraft:observer[facing=east,powered=false]
  S minecraft:stone
layer 0:
  SO
