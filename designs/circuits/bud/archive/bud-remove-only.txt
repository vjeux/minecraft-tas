# CIRCUIT: bud-remove-only bud detects remove, latency 5 gt, pulse 2 gt, re-arm 6 gt, footprint 2 cells, tileable every 3 (0 0 3), 4 blocks, 2x4x1, robust
name: bud-remove-only
circuit: bud
tile: 0 0 3
# Tells when a block is taken away from the target, and ignores its placement and the target's own
# changes: 4 blocks. A redstone torch under the target powers any solid block placed there, which
# powers the sticky piston beside it; the piston lifts its observer. When the block is removed the
# piston pulls the observer back down, and it fires once as it lands, into the output cell behind
# it (a 2-tick pulse); lifted, it fires one cell higher, away from the output. Detail: turning the
# block in place, a shape-only change or a pure update leaves the piston as it is: not detected.
origin: 0 -1 0
port target: 0 0 0
port output: 1 1 -1
palette:
  T minecraft:redstone_wall_torch[facing=west,lit=true]
  B minecraft:stone
  P minecraft:sticky_piston[extended=false,facing=up]
  O minecraft:observer[facing=south,powered=false]
layer 0:
  TB
layer 1:
  .P
layer 2:
  .O
