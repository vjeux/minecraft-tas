# A 1-cell presence detector: the redstone torch under the target powers a solid block placed
# there, which powers the dropper beside it; the dropper's triggered flag is set and cleared by
# that very update (a flags-2 change), so the observer watching it fires 2 gt after the block is
# placed or removed. Turning the block in place keeps it powered, a shape-only change or a pure
# update changes nothing: not detected. Found by `mctas circuit bud census --k 3`; the empty
# dropper clicks when it fires.
