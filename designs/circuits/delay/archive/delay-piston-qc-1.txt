# CIRCUIT: delay-piston-qc-1 delay N 1 gt, min-pulse 3 gt, min-gap 3 gt, 6 blocks, 3x2x2, robust
# Delay line N = 1 gt, update-correct (track delay): the input (a redstone block written above dust
# E) powers E (15), which feeds dust D (14) between it and the output cell; at rest a redstone block
# south of D powers it (15) and bends it north-south. The input also reaches the sticky piston beside
# E by quasi-connectivity (the input touches the cell above the piston; E's power change updates the
# piston), which pushes the block east next to the output: 1 gt after the rise the block leaves D,
# which straightens into the output AND drops from 15 to 14 (a power change: the output cell gets the
# block update); 3 gt after the rise the block lands next to the output and holds it on for the gt
# after the fall, until the piston pulls it back 1 gt after the fall.
