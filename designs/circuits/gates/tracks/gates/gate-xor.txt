# XOR gate, 21 blocks, 2 ticks: two subtract comparators, each with one input behind it and the other at its side, so each lights only when its own input is on alone. The trick is the side feeds: a dust lying ON input A's block reaches the upper comparator's side, and a dust UNDER input B's block reaches the lower one's, each at full strength because it touches the powered input block itself, so the two inputs cross in height instead of around each other. The lower comparator lights the lamp directly; the upper one powers a block whose dust climbs over the core and lands on the lamp. A stone above A's dust keeps that dust from joining the route over the top.
