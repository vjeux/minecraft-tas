# XOR gate, 16 blocks, 2 ticks: two subtract comparators, each with one input behind it and the other at its side, so each lights only when its own input is on alone. The side feeds cross in height instead of around each other: a dust lying ON input A's block reaches the upper comparator's side, and a dust UNDER input B's block reaches the lower one's, each at full strength because it touches the powered input block itself. The lower comparator lights the lamp directly; the upper one powers a block whose dust climbs over the core (across the stone that keeps A's dust from joining it, then down a stone sitting on the lower comparator) onto the lamp.
