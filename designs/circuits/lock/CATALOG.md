| [lock3-two](archive/lock3-two.txt) | lock 3 | dials 3, combinations tried 1024 (512 per code, 2 codes), opens within 6 gt, closes within 8 gt | 68 | 6x3x8 | robust | Put any item in each of the six item frames; a frame turns through 8 positions, one right-click each. All six frames are on the west wall: the three dials in the recessed column, each dial's code frame on the block sticking out just south of it. Set the code by turning the code frames, then turn the dials to match them: the torch under the north end lights (open) only when every dial shows the same position as its code frame, and never for a moment while you turn. Wire a piston door or an iron door to that torch. Inside, two comparators per dial: the first passes the dial's value only if it is at least the code (else a torch under its dust lights), the second passes the code only if it is at least the dial's value (else a torch on its block lights). One dust line under all six torches joins every mismatch into the block under its north end, which turns the output torch off (opens within 6 ticks, closes within 8). |
