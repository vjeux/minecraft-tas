| [lock3-q85](archive/lock3-q85.txt) | lock 3 | dials 3, combinations tried 1024 (512 per code, 2 codes), opens within 8 gt, closes within 10 gt | 85 | 6x3x9 | robust | Put any item in each of the six item frames; a frame turns through 8 positions, one right-click each. Set the code by turning the three code frames on the east side, then turn the three dials on the west side to match them: the torch at the south end lights (open) only when every dial shows the same position as its code frame, and never for a moment while you turn. Wire a piston door or an iron door to that torch with a dust line. Inside, one comparator per dial reads the dial frame directly and subtracts its code frame's value minus one: 0 means too low, 1 the code, 2 or more too high. A torch under each comparator's first dust catches too low (a repeater carries it toward the bus), a repeater after the second dust catches too high, and one dust line along the east side joins every mismatch into the block under its south end, which turns the output torch off (opens within 8 ticks, closes within 10). The code lines sit one level down, so the dials stack 3 blocks apart. |
