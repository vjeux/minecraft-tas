# CIRCUIT: counter11-ring11 counter 11 N 11, output level every 11 pulses, 32 blocks, 7x3x4, robust
# Counter 11, dropper ring, 32 blocks (track memory, `mctas circuit memory ring --n 11`): the input cell fires 11 droppers (2 next to it, 9 through 1 dust and 1 repeater relay (a repeater strongly powers a stone, a cross dust past it powers an outer stone, both fire their neighbours)), and 11 hoppers between them close the cycle dropper -> hopper -> dropper; each pulse fires every dropper, only the one holding the stone moves it, and its hopper delivers it to the next dropper after all have fired, so the stone advances one dropper per pulse whatever the firing order. The comparator reads one dropper: on during one pulse window in 11 (level style). The input sits on the build's edge (nothing south of it), where a real input line reaches it.
