# CIRCUIT: counter13-ring13 counter 13 N 13, output level every 13 pulses, 39 blocks, 6x3x6, robust
# Counter 13, dropper ring, 39 blocks (track memory, `mctas circuit memory ring --n 13`): the input cell fires 13 droppers (2 next to it, 11 through 0 dust and 2 repeater relays (a repeater strongly powers a stone, a cross dust past it powers an outer stone, both fire their neighbours)), and 13 hoppers between them close the cycle dropper -> hopper -> dropper; each pulse fires every dropper, only the one holding the stone moves it, and its hopper delivers it to the next dropper after all have fired, so the stone advances one dropper per pulse whatever the firing order. The comparator reads one dropper: on during one pulse window in 13 (level style). The input sits on the build's edge (nothing south of it), where a real input line reaches it.
