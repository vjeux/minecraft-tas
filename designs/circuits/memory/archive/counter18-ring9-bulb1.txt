# CIRCUIT: counter18-ring9-bulb1 counter 18 N 18, output level every 18 pulses, 28 blocks, 9x3x3, robust
# Counter 18, dropper ring + 1 copper bulb, 28 blocks (track memory, `mctas circuit memory ring --n 9 --bulbs 1`): the input cell fires 9 droppers (2 next to it, 7 through 2 dust), and 9 hoppers between them close the cycle dropper -> hopper -> dropper; each pulse fires every dropper, only the one holding the stone moves it, and its hopper delivers it to the next dropper after all have fired, so the stone advances one dropper per pulse whatever the firing order. The comparator reads one dropper: on during one pulse window in 9, and toggles a chain of 1 bulb T flip-flop (bulb + comparator), each halving the rate (level style).
