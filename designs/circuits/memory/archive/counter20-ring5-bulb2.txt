# CIRCUIT: counter20-ring5-bulb2 counter 20 N 20, output level every 20 pulses, 17 blocks, 7x2x3, robust
# Counter 20, dropper ring + 2 copper bulbs, 17 blocks (track memory, `mctas circuit memory ring --n 5 --bulbs 2`): the input cell fires 5 droppers (5 next to it), and 5 hoppers between them close the cycle dropper -> hopper -> dropper; each pulse fires every dropper, only the one holding the stone moves it, and its hopper delivers it to the next dropper after all have fired, so the stone advances one dropper per pulse whatever the firing order. The comparator reads one dropper: on during one pulse window in 5, and toggles a chain of 2 bulb T flip-flops (bulb + comparator), each halving the rate (level style).
