# CIRCUIT: counter22-ring11-bulb1 counter 22 N 22, output level every 22 pulses, 35 blocks, 7x3x4, robust
# Counter 22, dropper ring + 1 copper bulb, 35 blocks (track memory, `mctas circuit memory ring --n 11 --bulbs 1`): the input cell fires 11 droppers (2 next to it, 9 through 1 dust and 1 repeater relay (a repeater strongly powers a stone, a cross dust past it powers an outer stone, both fire their neighbours)), and 11 hoppers between them close the cycle dropper -> hopper -> dropper; each pulse fires every dropper, only the one holding the stone moves it, and its hopper delivers it to the next dropper after all have fired, so the stone advances one dropper per pulse whatever the firing order. The comparator reads one dropper: on during one pulse window in 11, and toggles a chain of 1 bulb T flip-flop (bulb + comparator), each halving the rate (level style). The input sits on the build's edge (nothing south of it), where a real input line reaches it.
