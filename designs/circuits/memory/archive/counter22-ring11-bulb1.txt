# CIRCUIT: counter22-ring11-bulb1 counter 22 N 22, output level every 22 pulses, 32 blocks, 9x3x3, robust
# Counter 22, dropper ring + 1 copper bulb, 32 blocks (track memory, `mctas circuit memory ring --n 11 --bulbs 1`): the input cell fires 11 droppers (3 next to it, 8 through 2 dust), and 11 hoppers between them close the cycle dropper -> hopper -> dropper; each pulse fires every dropper, only the one holding the stone moves it, and its hopper delivers it to the next dropper after all have fired, so the stone advances one dropper per pulse whatever the firing order. The comparator reads one dropper: on during one pulse window in 11, and toggles a chain of 1 bulb T flip-flop (bulb + comparator), each halving the rate (level style).
