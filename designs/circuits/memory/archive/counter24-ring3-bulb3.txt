# CIRCUIT: counter24-ring3-bulb3 counter 24 N 24, output level every 24 pulses, 17 blocks, 9x3x2, robust
# Counter 24, dropper ring + 3 copper bulbs, 17 blocks (track memory, `mctas circuit memory ring --n 3 --bulbs 3`): the input cell fires 3 droppers (3 next to it), and 3 hoppers between them close the cycle dropper -> hopper -> dropper; each pulse fires every dropper, only the one holding the stone moves it, and its hopper delivers it to the next dropper after all have fired, so the stone advances one dropper per pulse whatever the firing order. The comparator reads one dropper: on during one pulse window in 3, and toggles a chain of 3 bulb T flip-flops (bulb + comparator), each halving the rate (level style).
