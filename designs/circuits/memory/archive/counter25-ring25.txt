# CIRCUIT: counter25-ring25 counter 25 N 25, output level every 25 pulses, 72 blocks, 10x3x9, robust
# Counter 25, dropper ring, 72 blocks (track memory, `mctas circuit memory ring --n 25`): the input cell fires 25 droppers (1 next to it, 24 through 1 dust and 3 repeater relays: a repeater strongly powers a stone, a cross dust past it powers an outer stone, both fire their neighbours), and 25 hoppers between them close the cycle dropper -> hopper -> dropper; each pulse fires every dropper, only the one holding the stone moves it, and its hopper delivers it to the next dropper after all have fired, so the stone advances one dropper per pulse whatever the firing order. The comparator reads one dropper: on during one pulse window in 25 (level style).
