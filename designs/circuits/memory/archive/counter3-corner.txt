# CIRCUIT: counter3-corner counter 3 N 3, output level every 3 pulses, 8 blocks, 3x3x2, robust
# Counter 3, dropper corner ring, 8 blocks (track memory): the input cell touches three droppers on three axes (east, up, south); between each pair a hopper carries the stone on to the next dropper (dropper up -> hopper west -> dropper south -> hopper down -> dropper east -> hopper north). Each pulse fires all three; only the one holding the stone moves it, and its hopper delivers it after all three have fired, so the stone advances one dropper per pulse whatever the firing order. The comparator reads the east dropper: on during one pulse window in three (level style).
