# CIRCUIT: counter3-ring3-bulb1-div counter 3 N 3, output toggles every 3 pulses, 11 blocks, 5x3x2, robust
# Counter 3 as a divider, dropper ring + 1 copper bulb, 11 blocks (track memory, `mctas circuit memory ring --n 3 --bulbs 1 --divider`): the input cell fires 3 droppers (3 next to it), and 3 hoppers between them close the cycle dropper -> hopper -> dropper; each pulse fires every dropper, only the one holding the stone moves it, and its hopper delivers it to the next dropper after all have fired, so the stone advances one dropper per pulse whatever the firing order. The comparator reads one dropper: on during one pulse window in 3, and toggles a chain of 1 bulb T flip-flop (bulb + comparator), each halving the rate (the last comparator changes state once every 3 pulses: toggles style).
