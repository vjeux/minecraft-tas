# CIRCUIT: counter34-ring17-bulb1 counter 34 N 34, output level every 34 pulses, 50 blocks, 9x3x7, robust
# Counter 34, dropper ring + 1 copper bulb, 50 blocks (track memory, `mctas circuit memory ring --n 17 --bulbs 1`): the input cell fires 17 droppers (1 next to it, 16 through 4 dust), and 17 hoppers between them close the cycle dropper -> hopper -> dropper; each pulse fires every dropper, only the one holding the stone moves it, and its hopper delivers it to the next dropper after all have fired, so the stone advances one dropper per pulse whatever the firing order. The comparator reads one dropper: on during one pulse window in 17, and toggles a chain of 1 bulb T flip-flop (bulb + comparator), each halving the rate (level style).
