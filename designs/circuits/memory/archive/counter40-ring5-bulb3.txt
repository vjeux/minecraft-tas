# CIRCUIT: counter40-ring5-bulb3 counter 40 N 40, output level every 40 pulses, counts one pulse per N, on 20 of 40, 23 blocks, 4x3x8, robust
# Counter 40, dropper ring + 3 copper bulbs, 23 blocks (track memory, `mctas circuit memory ring --n 5 --bulbs 3`): the input cell fires 5 droppers (3 next to it, 2 through 1 dust), and 5 hoppers between them close the cycle dropper -> hopper -> dropper; each pulse fires every dropper, only the one holding the stone moves it, and its hopper delivers it to the next dropper after all have fired, so the stone advances one dropper per pulse whatever the firing order. The comparator reads one dropper: on during one pulse window in 5, and toggles a chain of 3 bulb T flip-flops (bulb + comparator), each halving the rate (level style). The input sits on the build's edge (nothing south of it), where a real input line reaches it.
