# CIRCUIT: counter5-ring5 counter 5 N 5, output level every 5 pulses, counts one pulse per N, 14 blocks, 4x3x2, robust
# Counter 5, dropper ring, 14 blocks (track memory, `mctas circuit memory ring --n 5`): the input cell fires 5 droppers (3 next to it, 2 through 1 dust), and 5 hoppers between them close the cycle dropper -> hopper -> dropper; each pulse fires every dropper, only the one holding the stone moves it, and its hopper delivers it to the next dropper after all have fired, so the stone advances one dropper per pulse whatever the firing order. The comparator reads one dropper: on during one pulse window in 5 (level style). The input sits on the build's edge (nothing south of it), where a real input line reaches it.
