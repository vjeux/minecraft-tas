# CIRCUIT: counter7-ring7 counter 7 N 7, output level every 7 pulses, 18 blocks, 3x3x4, robust
# Counter 7, dropper ring, 18 blocks (track memory, `mctas circuit memory ring --n 7`): the input cell fires 7 droppers (3 next to it, 4 through 1 dust), and 7 hoppers between them close the cycle dropper -> hopper -> dropper; each pulse fires every dropper, only the one holding the stone moves it, and its hopper delivers it to the next dropper after all have fired, so the stone advances one dropper per pulse whatever the firing order. The comparator reads one dropper: on during one pulse window in 7 (level style). The input sits on the build's edge (nothing south of it), where a real input line reaches it.
