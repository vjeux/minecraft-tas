# D flip-flop, repeater-lock master-slave: d runs through repeater A then repeater B to q. The clock locks A from the side through repeater L (a repeater's side lock reads only diodes, which the design owns), and the inverted clock, from torch T, locks B through repeater P. While the clock is low A follows d and B holds; on the rising edge A locks on d's value and B opens, so q takes d exactly at the edge.
name: dff-lock
circuit: dff
port input.d: -1 1 0
port input.clk: 0 1 3
port output: 2 1 0
origin: -1 0 0
