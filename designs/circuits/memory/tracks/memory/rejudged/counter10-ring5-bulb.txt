# CIRCUIT: counter10-ring5-bulb counter 10 N 10, output level every 10 pulses, 14 blocks, 5x2x3, robust
# Counter 10, dropper ring + 1 copper bulb, 14 blocks (track memory, `mctas circuit memory ring --n 5 --bulbs 1`): the input cell fires 5 droppers (5 next to it), and 5 hoppers between them close the cycle dropper -> hopper -> dropper; each pulse fires every dropper, only the one holding the stone moves it, and its hopper delivers it to the next dropper after all have fired, so the stone advances one dropper per pulse whatever the firing order. The comparator reads one dropper: on during one pulse window in 5, and toggles a chain of 1 bulb T flip-flop (bulb + comparator), each halving the rate (level style). The same waveform is "toggles every 5 pulses": a toggle counter N and a level counter 2N are one signal, so this card covers both readings (the removed counter5-ring*-div designs were this build under the other label).
