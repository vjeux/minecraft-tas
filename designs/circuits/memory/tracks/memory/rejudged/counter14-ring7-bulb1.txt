# CIRCUIT: counter14-ring7-bulb1 counter 14 N 14, output level every 14 pulses, 21 blocks, 7x3x3, robust
# Counter 14, dropper ring + 1 copper bulb, 21 blocks (track memory, `mctas circuit memory ring --n 7 --bulbs 1`): the input cell fires 7 droppers (4 next to it, 3 through 1 dust), and 7 hoppers between them close the cycle dropper -> hopper -> dropper; each pulse fires every dropper, only the one holding the stone moves it, and its hopper delivers it to the next dropper after all have fired, so the stone advances one dropper per pulse whatever the firing order. The comparator reads one dropper: on during one pulse window in 7, and toggles a chain of 1 bulb T flip-flop (bulb + comparator), each halving the rate (level style). The same waveform is "toggles every 7 pulses": a toggle counter N and a level counter 2N are one signal, so this card covers both readings (the removed counter7-ring*-div designs were this build under the other label).
