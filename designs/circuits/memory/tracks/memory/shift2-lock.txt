# 2-bit shift register: two repeater-lock master-slave stages in series, the first stage output feeding the second stage data, both clocked from one dust line. Each stage is a pair of repeaters on the data line whose lock repeaters sit beside them: the master lock reads the clock straight (so it follows d while the clock is low) and the slave lock reads it through a wall torch (so it follows while the clock is high), which makes q take d one clock edge later, and two stages make it two.
name: shift2-lock
circuit: shift 2
port input.d: -1 1 0
port input.clk: 3 2 3
port output: 4 1 0
origin: -1 0 0
