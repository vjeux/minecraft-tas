# CIRCUIT: pext-n2-sf7-2 piston-extender 2 N 2, extend 7 gt, retract 12 gt, 7 blocks, 5x2x3, robust
# N=2, slime-free, 7 blocks: an observer watching the input gives a 2 gt pulse on BOTH edges to A
# (through the stone beside it) and to a second sticky piston that carries an observer. On: A pushes
# B + payload and spits them (B lands next to the input, which holds it extended: the payload goes
# one more cell). Off: B retracts (payload back one), A's pulse reach-pulls B home, and the carried
# observer, pulled home too, fires on landing into B (variant 2: where it sits), whose 2 gt pulse
# reach-pulls the payload home. The lever hangs on the input observer.
