# moves (a piston's block event runs in the tick after the input changes), so they fire 1 gt apart
# on each edge; each feeds a delay-2 repeater (4 gt pulses) into one dust line, where the two
# pulses overlap into 4 + 1 = 5 gt.

port input: 1 1 0
