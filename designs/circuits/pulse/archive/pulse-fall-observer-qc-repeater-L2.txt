# A 2-tick falling-edge pulse for any input, even the shortest (2 ticks), 6 blocks: the 1-tick
# falling edge (when the input turns off, a sticky piston pulls a redstone block up for 1 tick)
# feeding a repeater that stretches that tick to 2 (the output is the repeater). Copies stand side
# by side every block. Detail: the observer watching the lower piston fires into the input block,
# so the upper piston pushes the redstone block straight back; feed the input block through a
# repeater. The repeater's delay sets the length.
