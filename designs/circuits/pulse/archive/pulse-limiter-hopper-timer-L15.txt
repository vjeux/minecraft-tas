# Cuts any input down to a length set by how many items sit in the first hopper: 8 ticks per item
# (less 1), from 7 ticks to over 2 minutes, always 7 blocks. Four hoppers in a square pass the items
# one by one; while the input is on, the items flow from the first hopper through the second one
# (whose comparator is the output, lit as long as items pass) into the last one; when the input
# turns off, a torch on the input block stops the first hopper and the items flow back into it.
# This one holds 2 items: 15 ticks.
