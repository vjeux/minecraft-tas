# CIRCUIT: pulse-limiter-psub-L7 pulse-limiter L 7 gt, delay 5 gt, min-pulse 10 gt, 10 blocks, 4x2x2, robust
name: pulse-limiter-psub-L7
circuit: pulse-limiter
group: pulse-limiter-psub
# Odd pulses (pulse-limiter, L = 7 gt): a subtract comparator's rear gets a redstone block that a sticky piston pushes behind it (the piston moves in the tick after the input changes and the block lands in the block-entity phase: an odd delay), its side gets the input through two repeaters (delays 2 and 3: an even delay); the output is on from the rear's arrival until the side's: L = 2 x (2 + 3) - 3 = 7 gt. A 1 gt input makes the piston leave its block behind the comparator until the next input pulls it back.
origin: 0 0 0
port input: 0 1 0
port output: 4 1 1
