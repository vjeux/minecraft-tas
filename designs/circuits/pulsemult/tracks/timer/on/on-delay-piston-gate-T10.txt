# The input's dust points into the empty cell X beside the output. A delay-3 repeater (6 gt) and two
# dust power a sticky piston that pushes a stone into X: the output is lit only while the stone is
# in X AND the input still powers it, so an input shorter than the repeater delay plus the piston's
# travel never lights it, and a longer one lights it for its length - 8 gt, going dark in the same
# tick as the input (the sticky piston pulls the stone back while the dust is already off). The
# repeater makes every piston pulse at least 6 gt, so the piston never spits its stone.

port output: 3 1 0
