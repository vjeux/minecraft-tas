# Filtering shulker loader (track shulker, hand-built): the always-on loader fed through a hopper
# item sorter, so only the filter item (cobblestone) goes into boxes and everything else goes on to
# the reject chest. The line hopper under the items chest pushes into the reject chest; the filter
# hopper below it holds 18 cobblestone and 4 named papers (its own, never moved), so it can only
# take cobblestone, which it pulls before the line hopper's 8 gt cooldown lets it go on. A
# comparator reads the filter hopper; through two dusts (the second one on only from signal 2,
# 19 cobblestone) and a repeater it feeds the side of a subtract comparator whose rear a torch keeps
# at 15, which locks the output hopper under the filter hopper: one more cobblestone unlocks it
# and it pulls one; the box's feeding hopper pulls from it, locked or not. The rest is the always-on
# loader (dispenser above the box cell, full detector, sticky piston two cells away, walled drop
# cell over the collection hopper, re-trigger observers).
