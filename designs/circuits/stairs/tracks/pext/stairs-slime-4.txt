# A hidden staircase of 4 steps (10 blocks, 3x5x6): flip the lever on and 4 slime-block steps slide
# out of the side wall, one block up each, from the floor to a ledge 4 blocks higher; flip it off and
# they slide back flush into the wall.
# How it works: the steps are slime blocks, joined by one more slime block under each step from the
# second on, so the whole staircase is one sticky piece that one sticky piston behind it pushes out and
# pulls back. The ledge at the top is obsidian, which slime cannot pull (another block there would be
# dragged into the wall with the steps). Slime steps bounce a fall and slow a walker: the stone
# staircase walks like normal ground (pext).
name: stairs-slime-4
circuit: piston-stairs 4
travel: 0 0 1
port stairs: 0 0 0
port input: -3 1 1 lever
origin: -3 0 -1
