# CIRCUIT: tnt-airburst tnt-duper rate 13.2 TNT/min, period 91 gt, per period 1, latency 5 gt, safe drop 0 blocks (on the ground), 58 blocks, 12x6x9, robust (survives its own explosions: 20 exploded, design intact; precise: 19 TNT at one point at fuse 1, in mid-air; launched at (-0.0049, 0.1568, -1.0000) blocks/gt, spread (0.0388, 0.0000, 0.0000); useful: every blast clear of fluids, each destroys blocks on open ground)
# A simpler precise air burst: every lit TNT explodes at exactly the same point in the air, bit
# for bit, with no long first jump. The slow duplicator (tnt-slow-launch-30b's engine) throws each
# TNT 4 blocks north into a fence post that stops it over a one-block water channel; the current
# pushes it east against a second fence post, which cancels the random sideways kick every TNT gets
# when it is lit (the first launch tick, while the TNT still moves along the post, closes even the
# last 0.0003 of a block the current cannot). An observer next to the engine sees the push that
# lights each TNT; a repeater hairpin and an observer line carry that pulse to a slime piston under
# the channel 58 game ticks later, which launches the TNT straight up, so it explodes at the top of
# its flight, almost 10 blocks above the channel and about 7 above the machine's top: the nearest
# block of the machine a blast could break is over 7 blocks away, beyond the reach of even the
# strongest blast (6.9 blocks). 58 blocks, against 75 for the first air burst (designs/circuits/
# tracks/tnt/precise/tnt-airburst-75b.txt), which flung each TNT 9 blocks first.
