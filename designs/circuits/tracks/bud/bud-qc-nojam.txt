name: bud-qc-nojam
circuit: bud
# A QC BUD that never jams: two NON-sticky pistons pass a package back and forth (a slime block with
# the arming redstone block on top and an observer stuck under it). Piston P is armed through
# quasi-connectivity by the redstone block; a block update reaching it pushes the package east (the
# redstone block lands beside the output). A non-sticky piston that retracts during its push
# leaves exactly what a normal retraction leaves, so a second update 2 gt later cannot strand
# anything. The moved observer fires 2 gt after landing, which updates piston Q, armed by the
# pushed redstone block through quasi-connectivity; by then P's head is gone (a non-sticky head
# vanishes at once), so Q pushes the package home, where the redstone block arms P again without
# updating it. Found by `mctas circuit bud census --base` (the two pistons + 1 block).
origin: 1 0 0
port target: 0 0 0
port output: 3 1 -1

  R minecraft:redstone_block

layer -1:
