name: pulse-dual-edge-reset
# One pulse of 30, 46, 62... ticks every time the input turns on and every time it turns off, for inputs held at least 2 seconds (40 ticks): a copper bulb in the input cell shows each change of the input to an observer, which lights a copper bulb that a loop of repeaters resets; each extra row of repeaters adds 16 ticks. Detail: extendable family dual-edge-reset (n = 0): dual-edge with L = 30 + 16n gt, 33 + 4n blocks. The observer watches the input cell's copper bulb (the input powers it, and its state changes on both edges; since R7 an observer cannot watch the judge's stone there) and fires through a repeater into a copper bulb (locked by a comparator reading the bulb while it is lit); the comparator also feeds a U of delay-4 repeaters into a second bulb, read by a comparator that an observer watches: its back faces the first bulb, so each loop sends one 2 gt reset pulse that turns the bulb off. Extension: lengthen the repeater U by one row: one more delay-4 repeater (on stone) in each column. Generator: mctas circuit pulse family dual-edge-reset --n N --out FILE.
circuit: dual-edge

extend group title: long pulse on both edges: an observer, two copper bulbs and a loop of repeaters
extend group note: Why a chain of repeaters: each change of the input must give the full pulse whatever the input does next, so the circuit has to remember it (the copper bulbs) and switch itself off after a delay; the constant-size hopper one-shots (13 blocks) answer one edge only, and a falling edge during their run would cut it short.
