name: pulse-dual-lock-L18
# One 18-tick pulse every time the input turns on and every time it turns off, for inputs held at least 2 seconds (40 ticks): a copper bulb in the input cell shows each change of the input to an observer, which lights a second copper bulb that a loop of repeaters turns off again. Detail: the observer watches the input cell's copper bulb (the input powers it, and its state changes on both edges; since R7 an observer cannot watch the judge's stone there) and fires through a repeater into a copper bulb (lit on a rising edge of its power); a comparator reads the bulb and feeds a lock (a repeater pointing into the trigger repeater's side: triggers are ignored while the bulb is lit, so short inputs cannot latch it) and a U of delay-4 repeaters back into the bulb, which turns it off one loop later. The loop keeps the bulb powered a loop longer, so the falling edge is answered only for inputs of 40 gt or more (generator: mctas circuit pulse family dual-lock --n 0).
circuit: dual-edge

group note: L set by the repeater U's length

port output: 3 1 0
