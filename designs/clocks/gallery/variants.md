# Clock variants

[catalog index](../CATALOG.md)

A variant is a clock with the same period as a smaller clock (its host: fewer blocks, or as many and better on a variation) with the same on-time and pulses per period, flat only if the host is, whatever its block kinds (palette alone is no distinction; materials, start, warmup and box height are not either); a clock that is not robust folds under a robust one of its period; the galleries show only the hosts. 725 variants of 147 hosts, by period. Generated by `mctas clock catalog`.
