# clk-sculk: the smallest verified clock per period

One design per period P (fewest blocks, then the smallest swept box), each judged ROBUST in the game and archived with `mctas clock archive` (this design or one of the same type). Built by `mctas clock sculk` (crates/clock-sculk; the generator line is the `# how:` comment) or found by `mctas clock census` with a sculk palette (census files) or by the long-period hunt `mctas clock sculk climb` + `reduce` (climb files). The output port is a cell whose own period is the clock's (`mctas clock sculk outputs --fix`); composites (no cell with the full period) are excluded. The extendable families (any n) are in ../extend/. Mechanisms: ../NOTES.md. Regenerate: `mctas clock sculk table --md designs/clocks/tracks/clk-sculk/best/*.txt`.
