name: gadget-comparator-odd
# Comparator subtraction on odd ticks: comparator C (subtract mode) has a redstone block behind it
# (rear 15) and gets its side input from redstone block R, which lever-fired sticky piston P moves.
# Output = rear - side, recomputed 2 gt after an input change (ComparatorBlock 145-146).
# Lever on: P pushes R at k1, R lands beside C in the block-entity phase of k3, C turns off at k5.
# Lever off: P pulls R away at k1 (the side input drops in the block-event phase), C is back on at
# k3. A comparator keeps the parity of its input: odd in, odd out (both edges here).
origin: -2 0 0

  C minecraft:comparator[facing=north,mode=subtract,powered=true]
