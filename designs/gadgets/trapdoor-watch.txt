name: gadget-trapdoor-watch
# An iron trapdoor is a power indicator that conducts nothing and needs no support
# (TrapDoorBlock: no canSurvive; neighborChanged reads hasNeighborSignal and sets OPEN and
# POWERED in the same tick with flag 2: no neighbor updates, but the shape update reaches an
# observer). Lever L feeds repeater R (delay 1), whose output points into trapdoor T: T opens at
# tick 2 and observer O watching it pulses ticks 4..5; piston Q right above T never moves (a
# stone block in T's place would pass the repeater's strong power up into Q). On lever off, T
# closes at tick 2 and O pulses again: one 2 gt pulse per edge, like a note block, but nothing
# next to the trapdoor is powered through it. Waxed copper trapdoors behave the same.
origin: 0 0 0
palette:
  S minecraft:stone
  L minecraft:lever[face=floor,facing=east,powered=false]
  R minecraft:repeater[delay=1,facing=west,locked=false,powered=false]
  T minecraft:iron_trapdoor[facing=north,half=bottom,open=false,powered=false,waterlogged=false]
  Q minecraft:piston[extended=false,facing=up]
  O minecraft:observer[facing=west,powered=false]
layer 0:
  SS
layer 1:
  LRTO
layer 2:
  ..Q
