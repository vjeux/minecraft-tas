# Archive of 2x2 door designs

Generated by `mctas door catalog` (and at the end of `door video-all`) from the files in this folder; never edit it by hand. Every design that verified, one file each, named `<name>-<blocks>b.txt` (the placed-block count it was archived with: an ID, not its size). **Size** = the door's volume, as the piston door community counts it (regulation section 4.2: the bounding box of the build over every state of a cycle, the lever excluded; `80b (8x10x1)`); blocks placed is secondary. Each file starts with its verify result and where it came from. New designs are archived by `mctas door verify <design> --extra-offsets 28 --archive` and by `door leaderboard --archive-dir`. Rules and boards: [docs/rules.md](../../../docs/rules.md); rankings: [WR.md](../WR.md); the story: [docs/history.md](../../../docs/history.md).

Hand-edited inputs: [records.tsv](records.tsv) (the solid record progression, also read by `door montage`), [captions.tsv](captions.tsv) (how each design works, also read by `door gallery`, `door montage` and `door leaderboard`), and `door buildable`'s scripts in [../tracks/buildable/scripts](../tracks/buildable/scripts) (the buildable column: a survival build order that ends in the judge's rest state, at how many of the 32 positions). Videos: `door video-all` (release `videos`). Ticks: worst of 3 cycles after each lever flip.

1 designs: 1 solid, 0 gravity, 0 sculk, 0 entity; 0 invalid ones kept for history.
