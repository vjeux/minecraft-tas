# Flat (1-wide) seamless 3x3 door mechanisms: the catalog per box

Generated by `mctas door families` (crates/piston-door/src/families.rs). Do not edit by hand.

Bounds: every block in the door plane; pistons sticky or normal facing E/W/U/D (retracted or extended at rest), at most **11 pistons**, no helpers, no slime/honey; every door block leaves the 3x3 in 1-2 unit moves (the center in exactly 2), each move a pull by a sticky piston 2 cells ahead or a push by a piston 1-2 cells behind, a piston reused from its rest cell or lifted 1 cell along its axis by one lift piston (the elevator). Each candidate is solved EXACTLY in the macro piston model (whole state graph, cap 300000 states): FULL seamless open state (3x3 empty, only door blocks / plain blocks in the 12 ring cells, nothing but air or a door block behind a swept ring cell that is empty when open), closing back to the exact rest state, everything inside the box at every state. Only MINIMAL mechanisms (no piston can be dropped), left-right mirror images merged (up/down is not a symmetry: quasi-connectivity and gravity).

Columns: box (W x H, door offset = columns left of / rows below the door), pistons (sticky), rest-ring = no piston/head in the ring at rest (the strict reading), sym = one pulse train for both lever edges (P = 2 gt pulse, L = level toggle; `+L` = needs levels), free = box cells the mechanism never touches (room for wiring), rq = pistons whose quasi-connectivity cell (above) is in the ring or the 3x3, wire = wiring feasibility (track box56's quadrant + parity argument, automated: free cells minus the ring, the swept cells and the cells behind open holes split into REGIONS; a piston is fed from a region touching it or the cell above it (QC) at every place it fires; a region with pistons only it can feed but no lever needs a LINK: a changing mechanism cell next to it an observer can watch, whose pulse count per lever edge must be odd where a piston there needs an odd count. Class A = one region feeds every piston; B = links needed, each with the right parity; C = some region only gets even links (needs a pulse merger, designs/gadgets/pulse-merge on explore/flat-seam); X = a piston no free cell feeds, or a region with no link), sim = `door ideal` replay with ideal inputs (oc = separate open/close schedules, sym = the shared train). Within a box, rows are ranked by wire class, forced regions, largest region, pistons, train length.
